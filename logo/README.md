# Paper Empire logo package

The selected identity is the **paper crown**: a folded-paper crown with one red torn corner, representing an empire with a visible crack.

- `mark.svg` — square/circular mark for profile images and watermarking.
- `wordmark.svg` — scalable horizontal lockup for headers and end cards.
- `paper-empire-profile-800.png` — 800px profile export.
- `paper-empire-watermark-150.png` — 150px watermark export.
- `paper-empire-banner-2560x1440.png` — YouTube banner export with safe-area placement.

Use ink `#141414`, newsprint `#E9E6DF`, grey fold `#C9C5BB`, and red ink `#D7261E`. Keep the red corner as the single red accent.
